# New Azure Resources to Add
# Based on Microsoft Azure naming conventions and common usage patterns

# 1. Azure Monitor Workspace
# - Slug: amws (Azure Monitor WorkSpace)
# - Length: typically 1-260 characters
# - Allows: letters, numbers, hyphens, underscores
# - Scope: resource group

# 2. Azure Managed Grafana
# - Slug: graf (shortened from grafana to follow 4-char pattern)
# - Length: typically 2-23 characters  
# - Allows: letters, numbers, hyphens
# - Must start with letter
# - Scope: resource group

# 3. Container App Job
# - Slug: cajob (Container App JOB)
# - Length: 1-32 characters
# - Allows: lowercase letters, numbers, hyphens
# - Must start with letter or number
# - Scope: resource group

# 4. Windows Function App
# - Slug: wfa (Windows Function App)
# - Length: 2-60 characters
# - Similar to regular function apps
# - Scope: global

# 5. Linux Function App  
# - Slug: lfa (Linux Function App)
# - Length: 2-60 characters
# - Similar to regular function apps
# - Scope: global
